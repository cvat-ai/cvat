The Audio Editor is the annotation interface for audio data. Instead of frames and shapes,
you work with labeled time intervals on an audio waveform.

![CVAT Audio Interfaces](/images/audio_editor_01.webp)

Use the Audio Editor to play a recording, create intervals for relevant time ranges, and assign
labels and attributes to each interval. Audio tasks open in this editor automatically.
