The Audio Editor objects sidebar contains the intervals list, label controls, and appearance
settings.

![Right Panel Objects](/images/audio_editor_rightbar_01.webp) ![Right Panel Labels](/images/audio_editor_rightbar_02.webp)

## Intervals list

| Image | Description |
| --- | --- |
| ![List](/images/audio_editor_rightbar_03.webp) | The list shows every interval in the job, including hidden intervals. <br>Click an item to make it active, or double-click it to play it once. |
| ![Sort by](/images/audio_editor_rightbar_05.webp) | Use **Sort by** to order the list by ID, start time, end time, duration, or label name. |
| ![Bulk controls](/images/audio_editor_rightbar_04.webp) | Bulk controls lock, pin, or hide all applicable intervals.<br><br>Default shortcuts:<br>Lock/Unlock all: <kbd>T</kbd>, then <kbd>L</kbd><br>Pin/Unpin all: <kbd>T</kbd>, then <kbd>P</kbd><br>Hide/Show all: <kbd>T</kbd>, then <kbd>H</kbd> |

## Interval actions

Each interval card includes playback, state, and more actions:

| Image | Description |
| --- | --- |
| ![Label](/images/audio_editor_rightbar_07.webp) ![Duration](/images/audio_editor_rightbar_08.webp) | The header shows the interval number, label, source when available, start and end time, and duration. Use the label selector to change its label. |
| ![Playback](/images/audio_editor_rightbar_09.webp) | Playback controls move the playhead to the interval start or end, or play the interval once.<br><br>Default shortcuts:<br>Set playback to start: <kbd>Shift</kbd>+<kbd>D</kbd><br>Play once: <kbd>Shift</kbd>+<kbd>Space</kbd><br>Set playback to end: <kbd>Shift</kbd>+<kbd>F</kbd> |
| ![State controls](/images/audio_editor_rightbar_10.webp) | State controls lock, pin, or hide the interval. Locked intervals cannot be edited, moved, or resized. Pinned intervals cannot be moved. Hidden intervals are not shown on the waveform.<br><br>Default shortcuts:<br>Lock/Unlock: <kbd>L</kbd><br>Pin/Unpin: <kbd>P</kbd><br>Hide/Show: <kbd>H</kbd> |
| ![More](/images/audio_editor_rightbar_11.webp) | The **More actions** menu lets you fit the waveform to the interval, copy its URL, duplicate it, change its color when available, or delete it.<br><br>Default shortcuts:<br>Fit interval: <kbd>I</kbd><br>Delete: <kbd>Del</kbd><br>Force-delete a locked interval: <kbd>Shift</kbd>+<kbd>Del</kbd> |

## Labels and appearance

| Image | Description |
| --- | --- |
| ![Labels](/images/audio_editor_rightbar_12.webp) | The labels section lets you manage interval visibility and locking by label. |
| ![Appearance](/images/audio_editor_rightbar_13.webp) | In **Appearance**, choose whether interval colors are determined by **Label** or **Instance** and adjust the general and selected interval opacity. |
