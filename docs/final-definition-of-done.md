# Definition of Done

- [ ] Task-level API returns annotation counts by class from the database.
- [ ] The endpoint refuses requests without a login and refuses users without task access.
- [ ] The page loads the graph and displays a clean empty state when no data exists.
- [ ] The page shows a clean error state when the request fails.
- [ ] Endpoint measurement is captured with 5 raw runs and a median result reported.
- [ ] The feature is explained and demonstrated in the Loom recording.
- [ ] Any unfinished work is explicitly listed with why it was deferred.
